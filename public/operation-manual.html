第1部：旅行者・現地観光 操作マニュアル（スマホ画面）

📍 1-1. 島到着時の「GPSチェックイン」操作手順

現地基本操作

港や空港に到着した旅行者が、現在地GPSを取得して島への到達を公式認定させる操作です。

  1. スマホで対象の島ページ（例: /island/aogashima）を開きます。
  2. 画面上部の大きな青色ボタン 「📍 現在地で到達チェックイン」 をタップ。
  3. ブラウザの「位置情報の使用を許可しますか？」ダイアログで必ず 「許可」 を選択。
  4. 数秒で島内GPSが認証され、「🎉 到達おめでとうございます！」 と紙吹雪演出が表示。
  5. 同時に島固有の「ご当地妖精」の図鑑登録モーダルが開き、コレクションに追加されます。

📶 1-2. 圏外（電波なし）での「自動一時保存＆復帰同期」

自動フェイルセーフ

携帯電波が届かない秘境や山間部でも、GPS衛星情報だけで到達を記録できる自動同期機能です。

  • 圏外での操作: 通常通り「📍 現在地で到達チェックイン」をタップすると、スマホ内に暗号化一時保存されます（「📶 圏外のため端末内に一時保存しました」と表示）。
  • 電波復帰時: 宿や港に戻って電波（4G/5G/Wi-Fi）が繋がると、アプリが自動検知して「📶 圏外で記録した島到達記録をサーバーへ自動同期しました！」と通知し、サーバー側へ完全反映されます。

📷 1-3. 写真データを使った「写真チェックイン」操作

後から認定
  1. 島ページ中段の 「📷 現地撮影写真でチェックイン」 をタップ。
  2. スマホのアルバムから、現地で撮影した風景や人物の写真を選択。
  3. 写真データ内に埋め込まれた撮影日時・GPS位置情報（Exif情報）を自動解析。
  4. 島内での撮影が合致すれば、写真撮影日時の到達記録として公式認定されます。

💳 1-4. 「公式到達認定証」の発行・物理カード注文手順

証明・物販
A. デジタル証明書（即時無料）

到達後に「公式到達証明書」をタップすると、日付・旅人名・シリアルナンバー入りの証書が生成されます。「💾 画像保存」でスマホのアルバムに保存可能。

B. 物理プラスチックカード注文（有料）

「💳 公式認定カードを取り寄せる」をタップし、受取人名・配送先住所を入力してStripeクレジットカード決済。後日追跡番号付きで自宅に届きます。

📸 1-5. SNS用「動的到達証明カード（X / Instagram）」生成手順

SNS拡散
  1. 島ページの 「📸 カード共有」 ボタンをタップ。
  2. 「X (Twitter) 向け」（1200×630px横型）または 「Instagram 向け」（1080×1920px縦型）を選択。
  3. 公認角印・島名・到達日が自動描画されたカードが生成されます。
  4. 「Xでシェア」を押すと、ハッシュタグ（#輝旅 #島専科 #島名）が自動入力された状態でX投稿画面が開きます。

第2部：管理CMS 実務操作マニュアル（PC画面）

2-1. 【公共Wi-Fi】新しいスポットを追加・編集する手順

画面: 公共Wi-Fiタブ
  1. 左サイドバーから 「公共Wi-Fi・電波インフラ」 をクリック。
  2. 画面上部のセレクトボックスで対象の島（例: `八丈島`）を選択。
  3. 右上の 「+ Wi-Fiスポットを追加」 をクリック。
  4. 施設名、SSID、設置場所、パスワードの有無、開庁時間などの補足を入力。
  5. 「保存する」 をクリック ➔ Supabase DBに永続保存され、監査ログに即時記録されます。

2-2. 【物理カード発送】注文確認から追跡番号登録・完了までの手順

画面: 発送・注文管理タブ
  1. 左サイドバーから 「発送・注文管理」 をクリック。
  2. ステータスが「未発送」（黄色バッジ）の行をクリックして詳細モーダルを開く。
  3. 注文者氏名、お届け先住所、島名、印字シリアルを確認してカードを封筒に梱包。
  4. 配送伝票の番号を「追跡番号」に入力し、「発送完了にする」 をクリック。
  5. ステータスが「発送済み」に切り替わり、注文者へ発送完了通知が自動送信されます。

2-3. 【店頭POP発行】島内店舗用のA4チラシを自動生成・印刷する手順

画面: 売店・加盟店タブ
  1. 左サイドバーから 「売店・加盟店パートナー」 をクリック。
  2. 対象店舗の右端にある 「🖨️ A4店頭POP」 ボタンをクリック。
  3. 店舗名、特大チェックインQRコード、店舗特典がA4縦でレイアウトされたプレビューを確認。
  4. 「A4印刷 / PDF保存」 をクリックして印刷またはPDF出力し、現地店舗へ提供。

2-4. 【動態レポート】議会・自治体提出用A4レポートとCSVの出力手順

画面: 動態レポートタブ
  1. 左サイドバーから 「自治体・動態レポート」 をクリック。
  2. 地域セレクターから「東京都」「沖縄県」などを選択。
  3. 「CSVダウンロード」: 文字化け防止（BOM付き）Excel対応データをダウンロード。
  4. 「A4レポート印刷」: 議会・幹部提出用のジャストサイズPDFを出力。

2-5. 【スタッフID発行】役場職員・観光協会へのアカウント付与手順

画面: 組織・スタッフ管理タブ
  1. 左サイドバーから 「組織・スタッフ管理」 をクリック。
  2. 右上の 「+ スタッフを追加」 をクリック。
  3. 氏名、メールアドレス、初期パスワード（8文字以上）、組織（例: 八丈町役場）、ロールを選択。
  4. 「スタッフを作成」を押すと、即座にログイン可能な暗号化ハッシュ付きアカウントが発行されます。

第3部：トラブルシューティング・例外対応

Q. 旅行者のiPhoneで「位置情報が利用できません」と出る場合の解除方法

iPhoneの「設定」➔「プライバシーとセキュリティ」➔「位置情報サービス」を「オン」にし、さらに「SafariのWebサイト」の「正確な位置情報」をオンにしてください。Safari画面内の「ぁあ」➔「Webサイトの設定」➔「位置情報」を「許可」にすることで解消します。

Q. 注文者から住所変更やキャンセルの連絡が来た場合

「発送・注文管理」で注文が「未発送」の場合、画面上でお届け先住所を手動編集できます。キャンセルの場合は「キャンセル（返金）」を押すとStripeを通じて全額自動返金されます。既に「発送済み」の場合は追跡番号をお客様にお伝えし、郵便局での転送をご案内します。

Q. 職員がパスワードを忘れた場合

組織管理者（Org Admin）またはマスター管理者がCMSにログインし、「組織・スタッフ管理」タブから対象スタッフの「パスワード再設定」を実行して新しいパスワードを伝達してください。
